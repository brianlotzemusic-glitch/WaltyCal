## 1. Cross-stitch patterns (PDF charts): NEW, not in the FACTORY.md list
Code fit: a chart is a grid of cells, a symbol per colour, a colour key and a stitch count, which is exactly what Python and PDF generation do well. A one-colour (monochrome) chart can be made directly by rasterising our existing silhouettes onto a 14-count grid and cleaning it by hand-written rules. Colour charts need careful pixel art at small sizes, which code can do with flat palettes.

## 2. Coloring pages (PDF)
Code fit: clean closed line art at a fixed stroke width is easy. "Bold & easy" (thick outlines, large regions) is the style that suits code best and is the current trend. Detailed adult pages need interior patterning (fur strokes, leaf veins, mandala fills), which code can generate but must be checked for clutter.

## Ruled out, and why
- **Machine embroidery** (PES/DST): demand is real. Embroidery fonts sell ~75/wk and ~67/wk ([font](https://ehunt.ai/research/best-etsy-font)), and eRank names "embroidery designs" a high-CTR top-200 search for Aug 2026. FACTORY.md bars it until there is a test stitch-out plan. Revisit if the owner can arrange a stitch-out. Category `12382` Embroidery Machine Files.
- **Crochet and knitting patterns**: the biggest digital-pattern sellers right now (a ghost granny-square pattern at ~314/wk, ≈2,700 per 60 days, **FLAG**; "crochet pattern" is an eRank top-10 search). They need worked and tested designs, which code can't produce.
- **Budget and wedding spreadsheets**: several are at 1,000+ per 60 days (**FLAG**, see Summary). They are off the Duskwood look, usually sold as Google Sheets (which need an owner Google account), and finance-adjacent. Worth flagging to the Scout as a possible separate venture; not an Etsy-shop format.
- **Canva templates, fonts, Procreate brushes**: excluded by FACTORY.md.
- **Tarot readings, PLR/MRR mega bundles, "digital product ideas" resale packs, franchise items** (Toy Story, Pokémon, Moana, Ghostface, Starscream): against the rules or not original work.
- **Frame-TV art and watercolour clipart in painted styles**: need painterly rendering we don't have.

## Caveats
- Every sales figure is an **EtsyHunt estimate** from a monthly-updated public top-10 list. "60-day" figures are weekly × 8.6 and assume the weekly rate held. Lifetime totals cap them.
- RankHero volumes are third-party estimates and look inflated against Etsy-only figures. Compare them with each other, not with the SVG keyword numbers in `themes-2026-10-01.md`.
- EtsyHunt has no public lists for coloring pages, bingo/party printables, gift tags, digital paper or tumbler wraps. For those formats the evidence is search data and isolated listings, not ranked sales.
- I couldn't check Bestseller badges, "in carts" or "bought in the last 24 hours" (Etsy returns 403).
- Pilot prices are proposals based on competitor prices. FACTORY.md's $4.00 rule is for 6-design cut-file bundles, so the Manager should confirm pilot pricing.
