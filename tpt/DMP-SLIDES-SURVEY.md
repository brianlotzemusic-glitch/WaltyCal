## 3. The owner's intro pattern and style (what to match)

- **Deck structure (Looping in Logic):** title slide with one pop-culture hook ("Feat. Billie Jean") -> plain-English definition ("What the heck is a loop?", 3 short bullets) -> listen-and-identify with a real song -> guided questions the class answers aloud (how many beats, how many measures) -> "what would the intro look like" worked example -> same thing shown in Logic -> rules of thumb (3 bullets, "based on YOUR taste, but...") -> link slide to the project sheet and rubric -> "One Last Thing" closer (image).
- **Project sheet pattern (every DMP2 sheet identical):** Overview paragraph in second person ("Your job is to...", "reverse-engineering"), Goals (4 bullets), Key Vocabulary (5 terms, bold term + one-line definition), Requirements, numbered Steps/Process (6-7, last is always Present and Get Feedback on Padlet with 3 questions), Tips for Success, Submission Checklist, Notes, Rubric /25 (5 categories scored 1-5, student and teacher average).
- **Day 1 post pattern (DMP1):** title "Unit name - Day 1, Digital Music Production 1 - Unit N"; numbered steps in bold verbs (Watch / Label / Listen / Open / Set up) each with one italic "why" line; boxed "Words you should own by the end of today"; Helpful Links.
- **Tone:** direct, second person, conversational, lightly humorous ("What the heck", "boring exercises"), hands-on first (feel it before you name it, per the Restructure principles); short sentences; checks for understanding by questions, not lecture.
- **Visual style:** not measurable from text export. Slides are text-light, image/screenshot-driven (Logic screenshots, a final image slide). No school logo seen in text; the BOE deck is school-facing, so branding check still needed (open question 1). Fonts/colours: unknown, ask or open one deck visually.
