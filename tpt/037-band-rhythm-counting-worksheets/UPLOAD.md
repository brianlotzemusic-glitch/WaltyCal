## 2. Description

```
Beginning Band Rhythm Counting Worksheets: students write in the counts under every note and rest, from quarter notes all the way to dotted rhythms and 6/8. 20 worksheets in 7 short units, each with 6 counting lines, plus answer keys for every line. Great for band, orchestra and general music in grades 5–8.

WHAT'S INCLUDED (34 pages, PDF, US Letter)
• Teacher notes with a unit guide and page list (1 page)
• Student reference: note and rest values, how to read each time signature, worked counting examples (1 page)
• 20 worksheets, 6 counting lines on each (20 pages)
• Answer keys for all 20 worksheets, two worksheets per page, with every count written in (10 pages)
• Terms of use and credits (1 page)

THE 7 UNITS
1. Quarter, half and whole notes and rests in 4/4 (worksheets 1–4)
2. 3/4 and 2/4 time (5–6)
3. Dotted half notes (7–8)
4. Eighth notes and eighth rests, counted 1 & 2 & (9–12)
5. Dotted quarter and eighth (13–14)
6. 6/8 time, counted 1 2 3 4 5 6 (15–17)
7. Mixed review and a challenge page with every meter (18–20)

HOW TO USE
Students check the time signature, then write the count in the box under each note or rest at the place where it begins. Rhythms are written on a one-line staff so the focus stays on counting, not pitch. Every line is generated by code so that each measure adds up to its time signature, and each answer key is built from the same data as its worksheet. Use for warm-ups, homework, quizzes, sub plans, or before sight-reading a new page in a method book.

• Grades 5–8
• Print in black and white; the answer keys use one accent color
• No ties and no sixteenth notes; no songs, lyrics or copyrighted characters

Created with the help of digital and AI tools. Notation and answer keys are verified before release.
```
