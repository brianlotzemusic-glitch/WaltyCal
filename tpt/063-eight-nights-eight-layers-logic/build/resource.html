What this is ·

A 3-class-period arrangement project for high school music technology. Every student builds 32 bars of music in Logic Pro, in eight sections of 4 bars, and each section adds one new layer, so the music grows from one layer to eight. Students choose a tempo, plan the layers, build and mix them, present the result and reflect on it. It is an original Hudson Beat project.

Quick start ·

  1. Read the pacing guide (page 5) and the teacher notes (pages 6–7).
  2. Look at the layer map, the layer cards and the tempo table (pages 11–13) and the setup (page 4).
  3. Print the student pages (pages 11–22), one set per student.
  4. Open the intro deck and read the speaker notes for Class 1.

The intro deck ·

Every slide has a class: Class 1 (slides 1–6), Class 2 (slides 7–9) and Class 3 (slides 10–14). Every slide has speaker notes.

Fonts: the deck uses Oswald and Source Sans 3 (free on Google Fonts, built into Google Slides). If PowerPoint or Keynote shows a different font, install the two fonts or present the PDF copy, which shows the intended look.

Eight Nights, Eight LayersProject overview
OVERVIEW
Layered arrangement project
The project in one line

Eight Nights, Eight Layers · Layered arrangement · Logic Pro
Eight sections, eight layers, one new layer each time.

What students make ·

An arrangement of 32 bars in eight sections of 4 bars, built in Logic Pro. It has a key, four chords, a tempo from 80 to 128 BPM and eight layers: a pad or drone, bass, kick and clap, hi-hat or shaker, chord stabs, an arpeggio, a counter-melody and a lead. One new layer joins at the start of each section, so section 1 has one layer and section 8 has all eight. Students hand in a bounced file and the zipped .logicx project, plus their plans and a reflection, then play the arrangement and take questions.

What this project reinforces ·

Teaches how a piece is built up in layers. Students learn what each layer in an arrangement is for, how to turn a tempo into bars and seconds with simple arithmetic, and how to mix so a new layer can be heard, all in Logic Pro, with a plan that grows one layer at a time.

Standards ·

Supports the National Core Arts Standards for Music (Music Technology, high school): generating and developing ideas (MU:Cr1.1, MU:Cr2.1), presenting work (MU:Pr6.1) and responding to it (MU:Re7.2).

Goals ·

  • Plan an arrangement of eight 4-bar sections in which each section adds exactly one new layer to the ones already playing
  • Use seconds per beat = 60 ÷ BPM and seconds per bar = 240 ÷ BPM in 4/4 to find how long the piece is and when each layer enters
  • Build eight layers in Logic Pro, each with its own sound and its own job: pad, bass, kick and clap, hi-hat, chord stabs, arpeggio, counter-melody and lead
  • Mix the arrangement so every layer can be heard when it joins, then bounce it and reflect on the choices

About the theme ·

Hanukkah (also spelled Chanukah) is an eight-night Jewish festival of lights. It remembers the rededication of the Second Temple in Jerusalem in the 2nd century BCE, and it begins on the 25th day of the Hebrew month of Kislev, which falls in late November or December. A hanukkiah, or menorah, has nine branches: eight for the nights and one more for the shamash, the “helper” candle that lights the others. One new candle is added each night.

This project borrows only that pattern as inspiration: one new layer for every section, so the music grows from one layer to eight. It is a music-technology project, not a religious activity, and it suits any class. Students may choose a different theme with eight steps, such as eight colors of a sunrise or eight stops on a journey. Families celebrate in many ways, and this kit does not say how anyone should.

SETUP
Teacher

You need ·

  • A Mac with Logic Pro for each student, and headphones.
  • A place to hand in the .mp3 or .wav files, the zipped .logicx and the reflection.
  • The layer map, layer cards and tempo table, printed (pages 11–13), or shown on the projector.
  • Printed student pages, one set each (pages 11–22).
  • A MIDI keyboard is optional: every note can be clicked in with the mouse.

Before Class 1 ·

Read the tempo table (page 13) so you can answer ‘when does the lead enter?’ for any tempo.
Open Logic Pro on a student computer and check which tools your version has: Session Players, Step Sequencer, Arpeggiator (see page 8).
Check that you can add a marker and repeat a 4-bar region to bar 33.
Read the worked example (pages 9–10).

What to watch ·

Watch for layers that start in the wrong section, arithmetic slips, layers that do the same job, and a mix so busy that new layers cannot be heard. A good listening day: play each student’s arrangement and ask the class to hold up fingers for how many layers they hear at the start of each section. The count should be 1, 2, 3 and so on up to 8. This kit prints no melody and names no songs or artists.

Ideas for the room
  • Ask while students work: which layer is new in this section? What is its job? What could you take away?
  • Say the theme plainly: the eight-night pattern is an inspiration for the structure, and students may choose another theme.
  • A student who is stuck can build the pad and the lead only: two layers already sound like an arrangement.

Melody (optional) ·

The lead in section 8 can be a melody the student writes, or any melody the student has the right to use. A class that would like a traditional Hanukkah song, such as Ma’oz Tzur, can bring a notated copy from a school or library collection and check that it is in the public domain. This kit does not print a melody chart.

Keep the volume moderate

Bright, high sounds and big drums can be tiring in headphones. Tell students to start low and check the final mix at a normal level.

TEACHER NOTES
1 of 2

What this project reinforces ·

Teaches how a piece is built up in layers. Students learn what each layer in an arrangement is for, how to turn a tempo into bars and seconds with simple arithmetic, and how to mix so a new layer can be heard, all in Logic Pro, with a plan that grows one layer at a time.

Common student struggles ·

  • The layers blur together: take a layer away, turn the pad down, and give each layer its own range, with the bass low and the lead high (page 15).
  • The arithmetic looks hard: work one entrance aloud with the formula start time = (section − 1) × 4 × (240 ÷ BPM), and let students check it by reading the time of a marker in Logic (page 13).
  • A new layer starts late or early: check that the region begins exactly on the first bar of its section, and that the markers are at bars 1, 5, 9, 13, 17, 21, 25 and 29 (page 8).
  • A student cannot find a pattern for a layer: use the idea on its layer card (page 12), or start with one note per bar and add one more idea only after it sounds right.

Suggested variations ·

Easier: Use a pad, a bass, a kick and clap and a lead only, four layers over four 8-bar sections, with a tempo of 100 BPM, where the 32 bars last exactly 76.8 seconds (page 13).

More Advanced: Plan two tempos, such as 100 and 120 BPM, and compare when each layer enters (page 13). Or take layers away again from section 9 on, so the arrangement builds to eight and then thins back to one, for a 64-bar piece.

Where this kit helps with each struggle
  • Layers that blur: the layer cards (page 12) give each layer a range and a job, and the mix checklist (page 15) covers pan and the low end.
  • The arithmetic: the tempo table (page 13) gives every section start time at 6 tempos, and the worked example (pages 9–10) shows each step.
  • Late or early entrances: the Logic quick reference (page 8) covers markers and repeating a region.
  • Not sure what to play: every card has a pattern idea, and the layer map (page 11) shows what is already playing.

How to grade ·

  • The rubric: five categories, each scored 1–5, /25 (page 19). Students score themselves first; the final grade is the average of their score and yours.
  • Layer Build (rubric row 1): play the bounce and count the layers at the start of each section: 1, 2, 3 up to 8 (page 11).
  • Tempo & Timing Math (rubric row 2): recompute one entrance time with the student: (section − 1) × 4 × (240 ÷ BPM) (page 13).
  • Sound & Roles (rubric row 3): open the project and compare the layers with the plan (page 14). Does every layer have its own job?
  • Arrangement & Mix (rubric row 4): listen for each entrance, check the meter for clipping and listen to the low end (page 15).
  • Plan & Reflection (rubric row 5): the arrangement plan, the feedback questions and the Reflection page (page 22) are the evidence.

Reflection ·

Every student reflects (page 22): a written or oral conversation about how you did on the project and what you would do differently next time. Students write it or talk it through with you; either way they answer the four prompts. Allow about 10 minutes after the presentations. Use it as evidence for the Plan & Reflection row of the rubric.

Notes / observations ·

A good listening day: play each student’s arrangement and ask the class to hold up fingers for how many layers they hear at the start of each section. The count should be 1, 2, 3 and so on up to 8. This kit prints no melody and names no songs or artists.

Eight Nights, Eight LayersLogic quick reference
SETUP
Teacher + student

Where to find the tools an Eight Nights, Eight Layers arrangement is likely to use. Demonstrate what your class needs on Classes 1 and 2 and then let students work. Names are from current Logic Pro versions; labels move between versions, so check yours.

Project and tempoFile › New…, then a Software Instrument track to start. Set the project tempo in the control bar to the number on your tempo table and keep the time signature at 4/4. The timing arithmetic only works at that tempo, so set it first. Set a cycle from bar 1 to bar 33 to hear all 32 bars.
Sections with markersShow the Marker global track (the Global Tracks controls or the View menu). Add a marker with the plus (+) button in that track, or with a Create Marker key command if your version has one, then drag or type it to bars 1, 5, 9, 13, 17, 21, 25 and 29. Name them Night 1 to Night 8.
Repeat a 4-bar ideaRecord or click in your four chords for 4 bars, then repeat the region to bar 33: use the Loop option for a selected region (look in the region inspector or press L), or drag the upper right corner of the region. Delete or mute the regions of layers that have not joined yet.
Session PlayersIf your version has Session Players, add a Drummer or a Bass Player track and let it follow your chords; choose a style, then check that it starts in the right bar. If your version does not have them, build the same parts with the instruments below.
Pad and leadMake a Software Instrument track and open Alchemy or Retro Synth, then look in the Library for a soft pad with a slow attack, or a bright lead. Play long chords for the pad. Stay in key with the white keys only, or switch on Scale Quantize if your version has it.
Kick, clap and hi-hatMake a Drum Machine Designer track (click the instrument slot and choose it), or use Quick Sampler pads. Click the hits in on the beats you planned. If your version has the Step Sequencer, it is a quick way to draw a pattern of hits.
ArpeggioPut the Arpeggiator MIDI plug-in in the MIDI FX slot of a Software Instrument channel strip, if your version has it, and hold a chord. Otherwise click the notes of the chord in one after another, in eighth notes.
Bass, stabs and counter-melodyUse Retro Synth or Alchemy patches (a bass patch low, a stab patch short). Keep the bass below the other layers, play the stabs on the off-beats and leave rests in the counter-melody.
Mixer, automation and bouncePress X for the Mixer and set levels and pan. Press A to show automation, choose a parameter such as track volume and click points to draw it: fade a new layer in, or push it up a little in its first section. Then File › Bounce › Project or Section (Command-B), MP3 or WAV, for the 32 bars. In Finder, Control-click the .logicx and choose Compress.

An invented plan on paper: an arrangement in A minor at 100 BPM. No audio is included. Student projects will differ. Page 1 of 2: the plan, the entrances and the tempo choice.

1 · A weak plan

I will add some sounds to a beat, and it will get bigger.

It names no tempo, no layers, no sections and no times.

2 · A clear plan

My arrangement is in A minor at 100 BPM in 4/4, with the chords Am, F, C and G, one chord per bar, repeated in every section. One bar lasts 240 ÷ 100 = 2.4 seconds, so a 4-bar section lasts 9.6 seconds and all 32 bars last 76.8 seconds. Night 1 is a pad. Each new section adds one layer: bass, kick and clap, hi-hat, chord stabs, an arpeggio, a counter-melody and, in section 8, the lead. The layers enter at 0, 9.6, 19.2, 28.8, 38.4, 48, 57.6 and 67.2 seconds, and section 8 plays all eight layers.

EXAMPLE
Teacher

The same arrangement, page 2 of 2: the map of the whole piece, then the numbers.

5 · The map: 32 bars, 8 sections, 8 layers ·

6 · Checking the numbers

One bar of 4/4 at 100 BPM lasts 240 ÷ 100 = 2.4 seconds, so 32 bars = 32 × 2.4 = 76.8 seconds, and 8 sections × 9.6 = 76.8 seconds too. A section starts at (night − 1) × 9.6 seconds: night 1 at 0, night 2 at 9.6, night 3 at 19.2, night 4 at 28.8, night 5 at 38.4, night 6 at 48, night 7 at 57.6, night 8 at 67.2. The layers playing in sections 1 to 8 are 1, 2, 3, 4, 5, 6, 7, 8, which add up to 36; at 4 bars each that is 144 layer-bars. The hi-hat plays 8 hits in each bar, so 32 hits in a section.

7 · The automation

Each new layer fades up over its first bar; the pad filter opens a little in every section; the lead is 2 dB above the counter-melody.

8 · Three feedback questions (invented)

1. Which new layer was easiest to hear when it entered, and why? 2. Did the arrangement feel like it was building? Where did it feel biggest? 3. Which layer would you take away first, and why?

9 · Moments to point out in class
  • Each entrance is on the first beat of bar 1, 5, 9, 13, 17, 21, 25 or 29, so every new layer starts exactly on a marker.
  • The kick and clap arrive in night 3. Before that, the pad and the bass have no beat, so the build starts as a slow wash and gets a pulse.
  • The lead arrives alone in section 8, after seven layers have set the key and the beat, so it is the climax.

Step 2: plan the layers. Each night adds one card. Read the card, try its tools if your version has them, and write down the sound you chose. Ideas are suggestions, not rules; every pattern should be your own.

Night 1 · Pad or drone

Its job: A long, soft sound that fills the background and sets the mood.

Try: Alchemy or Retro Synth: look in the Library for a pad patch with a slow attack.

Idea: Hold one chord, or one or two notes, for a whole bar or longer; follow your four chords.

My sound:
Night 2 · Bass

Its job: The low line under everything; it usually follows the root of each chord.

Try: Retro Synth or Alchemy bass patch; the Bass Player Session Player if your version has it.

Idea: Play one long note per bar on each chord’s root, then try a simple repeating pattern.

My sound:
Night 3 · Kick and clap

Its job: The steady backbone: a low kick and a sharp clap mark the beat.

Try: Drum Machine Designer, Quick Sampler, or the Drummer Session Player if your version has it.

Idea: Kick on beats 1 and 3, clap on beats 2 and 4.

My sound:
Night 4 · Hi-hat or shaker

Its job: Small, quick sounds that keep the pulse moving.

Try: Drum Machine Designer or Quick Sampler; the Step Sequencer if your version has it.

Idea: Eighth notes: two hits in every beat, counted 1 and 2 and 3 and 4 and.

My sound:
Night 5 · Chord stabs

Its job: Short, punchy chords that add harmony and rhythm.

Try: Any keyboard or synth Software Instrument with a short, quick release.

Idea: Play each chord on an off-beat, the “and” of a beat, and let it stop quickly.

My sound:
Night 6 · Arpeggio

Its job: The notes of a chord played one after another as a flowing pattern.

Try: The Arpeggiator MIDI plug-in on a Software Instrument track if your version has it, or click the notes in.

Idea: Take the notes of the chord that is playing and run them up and down in eighth notes.

My sound:
Night 7 · Counter-melody

Its job: A second melody that moves in the spaces and weaves around the main one.

Try: Alchemy or Retro Synth, or any Software Instrument whose sound stands out from the pad.

Idea: Write a short pattern of 4 to 8 notes, long and short, with rests where the lead will play.

My sound:
Night 8 · Lead

Its job: The main melody, clear and bright, at the top of the arrangement: the climax.

Try: An Alchemy or Retro Synth lead patch; a melody you write, or any melody you have the right to use.

Idea: Play it in the last section only; make it the loudest and brightest layer in the mix.

Step 1: choose key and tempo. In 4/4 there are 4 beats in a bar, and each section has 4 bars. These formulas turn a tempo into seconds. Every number below is computed, so you can check your own arithmetic against it.

The formulas (4/4)

Seconds per beat = 60 ÷ BPM

Seconds per bar = 240 ÷ BPM

Seconds per section = 4 × 240 ÷ BPM

32 bars = 32 × 240 ÷ BPM seconds

A section starts at (night − 1) × 4 × 240 ÷ BPM seconds

Example: 100 BPM: 240 ÷ 100 = 2.4 s per bar, 4 × 2.4 = 9.6 s per section, 32 × 2.4 = 76.8 s in all.

Rounding rules

Seconds per beat and per bar to 3 decimals, seconds per section and totals to 2, and a 5 rounds up. So 240 ÷ 90 = 2.667 seconds per bar, and 4 × 240 ÷ 90 = 10.67 seconds per section (10.666… rounds up). In the start table, every time is rounded to 2 decimals from its exact value.

Eight Nights, Eight Layers

Music Technology | Layered Arrangement Project | 3 class periods

Overview ·

Build an arrangement that grows. In Logic Pro, make 32 bars of music in eight sections of 4 bars each. Section 1 has one layer, a pad or drone. Every new section adds one more track: bass, kick and clap, hi-hat or shaker, chord stabs, an arpeggio, a counter-melody and finally a lead, so section 8 plays all eight at once. Choose a tempo with the tempo table: one bar of 4/4 lasts 240 ÷ BPM seconds, so the whole piece lasts 32 × 240 ÷ BPM seconds. Then mix it so each new layer is heard when it enters. Nobody needs to read music, and no melody is given.

Goals ·

  • Plan an arrangement of eight 4-bar sections in which each section adds exactly one new layer to the ones already playing
  • Use seconds per beat = 60 ÷ BPM and seconds per bar = 240 ÷ BPM in 4/4 to find how long the piece is and when each layer enters
  • Build eight layers in Logic Pro, each with its own sound and its own job: pad, bass, kick and clap, hi-hat, chord stabs, arpeggio, counter-melody and lead
  • Mix the arrangement so every layer can be heard when it joins, then bounce it and reflect on the choices

Key Vocabulary ·

LayerOne track in an arrangement with its own sound and its own job, such as a bass line or a hi-hat pattern
SectionA block of bars, here 4, in which the music repeats; in this project a new layer joins at the start of each section
ArrangementThe way layers and sections are put together over time so that a piece builds, thins out or changes
ArpeggioThe notes of a chord played one after another instead of all together, usually as a repeating pattern

Steps / Process ·

  1. 1
    Choose key and tempo — Pick a key and four chords, then use the tempo table (page 13) to choose a tempo from 80 to 128 BPM and work out how long your 32 bars last
  2. 2
    Plan the layers — Read the eight layer cards (page 12) and fill in the arrangement plan (page 14): which sound and which pattern for each night
  3. 3
    Set up Logic — Open a project at your tempo in 4/4, make a 4-bar region of your four chords, and put a marker at the start of each of the eight sections (Logic quick reference: page 8)
  4. 4
    Build nights 1 to 4 — Build the pad, the bass, the kick and clap and the hi-hat or shaker, one at the start of each of sections 1 to 4
  5. 5
    Build nights 5 to 8 — Add the chord stabs, the arpeggio, the counter-melody and the lead, one at the start of each of sections 5 to 8, until all eight play together
  6. 6
    Mix and bounce — Set levels, pan and automation with the mix checklist (page 15), then bounce your 32 bars and name the file as on the checklist
  7. 7
    Present & get feedback — Write three questions you want classmates to answer about your arrangement. Play it, point out each new layer as it enters, and answer at least 2 of each classmate’s questions. Then reflect (page 22).

Tips for Success ·

  • Get the first four bars sounding good before you add anything. Every later layer sits on top of them.
  • Leave space. A layer that plays all the time is harder to hear than one that rests now and then.
  • Give the new layer the spotlight: turn it up a little in its first section, then settle it back into the mix.
  • Save a new version of your project at the end of each night’s work, so you can always go back.
