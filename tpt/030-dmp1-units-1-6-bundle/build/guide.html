Teach the units in this order. It is the course order the units are numbered in, and each unit works as a stand-alone teaching unit.

UnitTitleDaysPeriodsStudents makeIn the folder

Pacing

  • The units are planned for about 53-minute class periods, 29 in all: about six school weeks if the class meets five days a week.
  • Each unit has its own minute-by-minute day plans (the pacing page near the front of its PDF). Unit 1 has a note on stretching to 5 days, and Unit 5 has a note on running in 3 days if you are short on time.

Why this order

  • Unit 2 builds on Unit 1, Beat From Nothing.
  • Unit 4 picks up where Unit 3 ends: students continue in their Unit 3 project, or use a file made from the recipe on its setup page.
  • Unit 5 arranges a chord progression and bassline students already have, so it follows Units 3 and 4. If they have none, its setup page shows a quick way to make one.
  • Unit 6 needs no key, chord progression or song form (students may work in any key), so you can move it earlier, for example to October for Halloween.

In every unit folder

  • The PDF: how to use, unit overview and setup, pacing and day plans, teacher notes, student pages, rubric and answer key.
  • The intro deck (.pptx): the teacher-presented slides, with speaker notes on every slide.
  • The intro deck (PDF): a copy that shows the intended look. The deck uses the free Oswald and Source Sans 3 fonts.

How to start

  1. Open this guide, then the folder for Unit 1.
  2. Read the unit PDF's how-to-use and pacing pages, then the teacher notes.
  3. Present the intro deck on Day 1 and print the student pages.

What you supply

  • Logic Pro on a Mac. The steps are written for Logic Pro; the music ideas carry over to other DAWs.
  • No audio, video, stems or Logic sessions are included. Where a unit needs a file (stems for Unit 2, a short bassline file for Units 3 and 4, a one-minute video for Unit 6), that unit's setup page explains how to make or find one.
  • Songs named in a unit are named for reference only; play them from your own streaming access.
