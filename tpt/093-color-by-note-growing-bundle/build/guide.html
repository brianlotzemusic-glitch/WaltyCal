How to use this bundle

  1. Unzip the download. Each set has its own numbered folder (01 to 06) holding that set’s PDF.
  2. Look at the next page: the table lists every set with its grades, page count and folder name.
  3. Open the PDF you need. Each one starts with a cover and a teacher page with a level guide and a page list; the answer keys are inside the same PDF.
  4. Choose the level for each student: Level A reads rhythm values, Level B reads treble clef note names, Level C reads bass clef note names (in the Color by Music Symbol set: dynamics, tempo terms and music symbols). Print the worksheets and hand out crayons.
